# 🛡️ Network Forensics Analysis System

### Real-Time Network Monitoring | Threat Detection | Security Analysis

A Python-based Network Forensics Analysis System designed to monitor network traffic, analyze packet-level information, identify suspicious activities, and generate security alerts through an interactive dashboard.

## 🚀 Project Overview

The Network Forensics Analysis System helps analyze network traffic and detect potentially malicious activities using packet analysis and threat detection techniques.

## ✨ Key Features

- 📡 Live Network Traffic Monitoring
- 📂 PCAP File Upload and Analysis
- 🔍 Packet-Level Analysis
- 🚨 Suspicious Activity Detection
- 📊 Interactive Security Dashboard
- 📋 Threat Alerts and Activity Logs
- 📑 Security Reports

## 🛠️ Technologies Used

- Python
- Flask
- Scapy
- HTML, CSS, JavaScript
- Network Packet Analysis

## 📁 Project Modules

1. Dashboard
2. Live Capture
3. PCAP Analysis
4. Threat Detection
5. Alerts Management
6. Reports
7. Settings

## ⚙️ Installation and Setup

2. Install the required dependencies.
3. Run the Flask application.
